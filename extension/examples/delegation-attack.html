Temporarily give the owner's address malicious EIP-7702 code in an RPC simulation. Test whether it can raise the spending limit, drain a simulated 10 CELO balance, or execute a call directly.

No private key, delegation signature, transaction or gas payment is needed. The simulation never broadcasts. It checks the selected smart account's contract guard, not every possible wallet attack.

The new deployment is selected. Optionally connect Paranoia to test your linked account instead.
